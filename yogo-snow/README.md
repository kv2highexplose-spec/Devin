# yogo-snow — 余呉高原リゾート・ヤップ特化 降雪予測モデル

滋賀県長浜市余呉町・栃ノ木峠にある
[余呉高原リゾート・ヤップ](https://yogo45.co.jp/)(標高540–740m)向けの
降雪予測モデル。気象庁系モデル(JMA GSM/MSM)の大気状態を入力に、
勾配ブースティングのハードルモデルで「雪が降るか」と「どれだけ降るか」を
時別に予測し、スキー場の3標高(麓/中腹/山頂)の日別降雪量に集計する。

## 設計

### データ源 (Open-Meteo, 無料・APIキー不要)

- **学習**: `models=jma_seamless` のアーカイブ(2016年冬〜)。
  GSM+MSM の解析値ベースで、圧力レベル変数まで揃う。
  ERA5は日本のこの地点で圧力レベルが返らないため採用せず。
- **予報**: `models=jma_msm`(メソモデル, 既定)または `jma_seamless`。
  学習と同じモデル系なので系統バイアスが少ない。

### 地点

| 点 | 座標 | 役割 |
|---|---|---|
| 主地点 | 35.6983N 136.158E | スキー場(標高640m代表) |
| 上流点 | 36.20N 135.70E | 若狭湾沖 — 季節風の水分供給源 |
| 東側点 | 34.70N 136.90E | 伊勢湾方面 — 「西高東低」の気圧勾配 |

### 特徴量 (`features.py`)

- **寒気**: T925/T850/T700/T500, 500hPa高度, T500≤-30°C の JPCZ 指標
- **季節風・fetch**: 850/925hPa風の u,v + `fetch_index`
  (風速 × max(0, cos(風向−335°)) — 若狭湾から余呉の山間へ
  雪雲が流れ込む方位への投影)
- **気圧配置**: 日本海側−太平洋側の海面気圧差(西高東低の強さ)
- **加湿**: 925/850/700hPa 相対湿度 + 上流点との850hPa気温・湿度差
- **雨雪判別**: Stull(2011)湿球温度
- **季節性・持続**: day-of-year sin/cos, fetch/850hPa気温の6h移動平均

### モデル (`model.py`)

ハードル型: `P(降雪あり)`(分類器) × `E[量|降雪]`(poisson損失の回帰器)。
ともに `HistGradientBoosting*`。出力に2つの補正を掛ける:

1. **地形性補正**: ERA5/JMA格子高度(553m)との差100mあたり+12%増減
2. **融解補正**: 目標標高に換算した湿球温度が0°Cを超えるほど減衰

### 精度 (2025-26冬を留出した時間分割検証)

- 季節累積降雪: 予測545cm / 解析509cm (+7%)
- 日別降雪 MAE 0.34cm、降雪検出 CSI 0.99
- 実例: 2026年1月の大寒波(1/21–25連続降雪)で期間累積 258cm vs 解析239cm

「実績」は気象庁解析値(≈モデル再解析)であり、スキー場実測の観測値ではない
点に注意。実測データ(スキー場公表の積雪やアメダス「余呉」)が取れれば、
`model.py` の補正係数をその実測に再較正するのが次の改善になる。

## 使い方

```bash
cd yogo-snow
pip install -r requirements.txt

python3 run.py train                    # 過去10冬を学習(最終冬は検証)
python3 run.py forecast                 # JMA MSM で今後16日の日別降雪
python3 run.py forecast --wx jma_seamless --png   # 長期 + グラフPNG
python3 run.py hindcast --start 2026-01-05 --end 2026-01-25 --png
python3 run.py evaluate                 # 保存済み検証指標
```

出力: 日別降雪表(麓540m/中腹640m/山頂740m)、気象モデル素の降雪との比較、
ピーク時の大気状態の日本語サマリ、`data/forecast.csv`、任意でPNG。

## 構成

```
run.py               — CLIエントリ
yogo_snow/
  config.py          — 地点座標・標高・変数リスト
  sources.py         — Open-Meteo取得(キャッシュ付)
  features.py        — 特徴量(湿球温度/fetch/気圧勾配…) + ルールベース指数
  model.py           — ハードル型GBM + 標高補正 + 保存/読込 + 評価
  pipeline.py        — train/forecast/hindcast + 日本語状況説明 + 描画
  cli.py             — サブコマンド
tests/               — pytest(湿球温度・fetch・モデル一貫性)
data/                — キャッシュ(parquet)と出力 (git管理外)
models/              — 学習済みモデル joblib
```

## 限界

- 気象モデルの解析・予報が入力なので、モデル自体の誤差は引き継ぐ
- 局地の実測で較正していないため絶対量は±数割の幅がありうる
- MSMの予報期間を超える先は GSM 側の荒い値が入る
