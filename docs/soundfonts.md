# SoundFont research matrix

Bundled fonts (in `site/library/soundfonts/`, loaded via `fonts.json`) **must** have
`redistributionAllowed: true`. Anything with unclear or personal-use-only licensing is
excluded from the repo and listed here for documentation only.

## Notes for adding a font

1. Verify the license text *in the font itself* (INFO/ICOP/ICMT chunks) or on the
   author's site — mirror metadata is not enough.
2. Put the file in `site/library/soundfonts/`, add an entry to `fonts.json` with all
   fields (`id, name, file, sourceUrl, license, licenseText, redistributionAllowed,
   sizeMB, tags, notes`), then run `pytest tests/test_library.py -k soundfont`.
